# Standalone news feed

QuantTrade serves the existing Pairlens `/api/news` response using public publisher RSS feeds: CoinDesk (https://www.coindesk.com/arc/outboundfeeds/rss), Cointelegraph (https://cointelegraph.com/rss), MarketWatch (https://feeds.content.dowjones.io/public/rss/mw_topstories), CNBC Earnings (https://www.cnbc.com/id/15839135/device/rss/rss.html), and CNBC Market Insider (https://www.cnbc.com/id/20409666/device/rss/rss.html). CNBC lists these feed categories at https://www.cnbc.com/rss-feeds/. Only headlines, publication times, publisher attribution and original article links are displayed; article bodies are not copied.

Equities All requests `financial_markets`; Earnings requires both `financial_markets,earnings`. Comma-separated topics are conjunctive. Genuine market-wide stories do not need a ticker tag to remain visible. Crypto-native publisher stories cannot enter this financial-markets wire solely by mentioning a stock such as Tesla. Macro remains cross-market. Equity ticker metadata covers the terminal's stock catalog using conservative company-name and explicit ticker matching; ambiguous words such as “strategy” and “cat” do not identify a stock. Titles are decoded as plain text, including numeric/hexadecimal and double-escaped entities. If every source for a requested wire fails, that wire is unavailable rather than an empty result supplied by a surviving unrelated feed.

Downloads use fixed HTTPS destinations, 12-second timeouts, two-megabyte stream limits and a two-minute shared cache. Unsafe XML entity declarations and unsafe/non-publisher links are rejected. A surviving source can supply the feed; total source failure returns the native news_unavailable error. Available feed history is limited to publishers' current RSS windows, not a historical archive. Tickery metadata and macro/earnings topic tags use conservative headline keyword matching; neutral sentiment fields mean no sentiment analysis is supplied. Crypto BTC+ETH scope selects the crypto wire, including other token headlines.

The four public data routes bypass the generic missing-cloud response but retain bridge host/origin guards, bounded request concurrency/rate limits and no execution access. Other unavailable private cloud services continue to return503 without browser Basic challenges.

Hosted source check (2026-10-16): MarketWatch returned HTTP200 and ten current headlines. Both CNBC endpoints returned HTTP403 from Hetzner despite working from the development computer. They remain optional sources; no access controls are bypassed. Earnings is a filtered current-headline window and may be empty when reachable publishers have no matching stories. It is not an earnings calendar or guaranteed full-market coverage.
