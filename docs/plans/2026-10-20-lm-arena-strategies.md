# LM Arena: description-first strategies

The user wants to describe a trading agent rather than configure a name and one coin. The product name is **LM Arena**; **Paper** and **Live** are explicit execution modes. A description produces an unsaved editable strategy proposal. Saving produces a paused agent; starting is separate. Live start binds the selected configured account and connection revision with explicit autonomous-execution consent. QA never arms Live.

Each agent selects one venue and a market universe: a single exact native contract, an exact watchlist, or eligible USDC perpetuals from the venue catalog. A deterministic liquidity/risk filter builds a small bounded shortlist before the one scheduled model decision. The model may select only an instrument present in that inference snapshot, or hold/close the existing owned position. The initial runtime allows one open position per agent at a time; it is not restricted to one coin across its lifetime. No arbitrary model tools, code execution or changing risk settings are allowed.

The strategy description, market scope, timeframe, schedule, leverage, margin mode, fixed entry margin, stop/take-profit and AI/daily-loss/notional caps remain editable. Proposed defaults are reviewable suggestions, not previous user approvals. Market scanning and protective checks do not call the LLM. The model wakes on a bounded schedule and per-day call/spend limits; no profitability guarantee or claim of continuous high-frequency execution.

Legacy single-symbol agents migrate without changing their contract or starting them. Position symbol and selected-market evidence are persisted independently of the watchlist. Pause/restart/credential changes revoke new trading authority. Existing native protections stay in place. Uncertain submission outcomes must be reconciled without retrying them. Live account availability and unsupported shared-collateral modes remain explicit; selecting Live does not provision a new wallet.

Verification includes off-universe model selections, stale/missing histories, leverage/margin/funding/volume filters, no eligible candidates without paid inference, bounded candidate context, persistence and close/reopen on a different market, Live ownership/risk mocks, editable draft lifecycle, mode switching while flat, and desktop/mobile forms.
