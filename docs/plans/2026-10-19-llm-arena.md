# LLM Arena first version — implementation contract

Goal: server-run paper portfolios for comparison of user-selected NanoGPT models. Live autonomous trading is a later phase using dedicated wallets the user will select; it is not activated or claimed by this first version. User explicitly chose paper first and configurable AI spend/daily loss limits. Keep existing script bots intact.

Runtime: one bounded JSON decision per scheduled wake (15–1440 minutes), max1200 output tokens, input limited to48candles. Cheap mark/SL/TP/loss checks run every30seconds, no LLM call. Exact venue/symbol/model and deterministic fixed sizing/leverage/SL/TP rules. No model tool execution, arbitrary code or risk-setting changes. Model can hold/long/short/close only. Each bot has an independent paper ledger. Provider key only in memory, lease24hours; restart pauses bots and requires a new start. No real orders/proposals during arena paper runs.

AI budget: fresh public NanoGPT catalog pricing, reserve conservative full context + bounded output cost before each model request; no calls when reservation exceeds remaining daily cap. Invalid/missing usage conservatively consumes reservation; no transparent provider retry that escapes budget. Missing pricing disables starts. Budgets/fees/funding assumptions visible. No profitability guarantees.

API prefix /_quanttrade/api/llm-arena in frontend (server /api/llm-arena). Operator-only, same hosted origin checks.
GET / => {bots:ArenaBot[],capabilities:{paper:true,live:false}}
GET /models => {models:[{id,name,inputPerMillion,outputPerMillion,contextLength}],updatedAt}
POST / => create paused bot from config below, returns ArenaBot.
PATCH /:id => update config while paused; initialEquity immutable; changing venue/symbol forbidden with open position.
POST /:id/start {apiKey:string} => start existing bot with NanoGPT key in-memory for24h.
POST /:id/pause {} => pause model decisions; cheap protective checks continue, clear in-memory key.
POST /:id/evaluate {} => evaluate now only if running, uses same budget and min60sec cooldown.
POST /:id/close-position {} => close paper position at fresh venue book, never live.
POST /:id/archive {archived:boolean} => paused + flat only.

Config: {name:string,model:string,venue:'lighter'|'hyperliquid',symbol:string,intervalMinutes:number,initialEquity:number,marginPerTrade:number,leverage:number,maxDailyLoss:number,maxAiSpendDaily:number,maxRunsDaily:number,stopLossPct:number,takeProfitPct:number,minVolume24h:number,maxAbsFundingBps:number,allowedSide:'both'|'long'|'short',minConfidence:number,feeBps:number,slippageBps:number,rules:string}. All numeric values finite bounded and positive where applicable. Paper quote currency USD; fee/slippage configurable assumptions. Snapshot funding treatment explicitly stated in UI.

ArenaBot: {id,config,status:'paused'|'running'|'error'|'needs-key'|'budget-paused'|'loss-paused',reason:string|null,archived:boolean,nextWakeAt:number|null,leaseExpiresAt:number|null,createdAt:number,updatedAt:number,paper:{cash:number,equity:number,realizedPnl:number,peakEquity:number,maxDrawdownPct:number,closedTrades:number,winningTrades:number,feesPaid:number,fundingPaid:number,position:null|{side:'long'|'short',size:number,entryPrice:number,margin:number,leverage:number,stopPrice:number,takeProfitPrice:number,openedAt:number,lastFundingAt:number}},daily:{date:string,startEquity:number,aiSpent:number,calls:number},history:[{at:number,action:string,status:string,rationale:string,cost:number,estimatedCost:boolean}],equityCurve:[{at:number,equity:number}]}. Bounded history/curve. Server never serializes keys.

UI: Bots page tabs Strategy bots / LLM Arena; compact master-detail arena list/ranking. Create/edit rule form, daily AI budget and loss caps required, model selection + interval, paper bankroll, SL/TP and precisevenue/symbol. Start/pause/evaluate/close paper position/archive; budgetconsumption/nextwake/leaseexpiry clear. No auto-start, no live execution. Read saved NanoGPT key only through existing official-config/ledger credential APIs, no localStorage bypass; if unavailable guideconnectplugin. Start copies key to server memory explicitly in UI. Do not change selected assistant model. Charts can be simple established SVGlinecharts of real paper equity; no invented history. Responsive compact layout and empty/error/loading states.
