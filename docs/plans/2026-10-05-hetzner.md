# Hetzner QuantTrade Implementation Plan

**Goal:** Deploy the full QuantTrade terminal and a running Hummingbot backend on the existing Hetzner host, retaining human approval and paper mode.

**Architecture:** Nginx serves the native static SPA and proxies its private QuantTrade bridge. Node24 runs the bridge under systemd, bound to loopback. Hummingbot API and its broker/database use isolated Docker services with loopback-only API publishing. Existing websites, Watchtower, and databases remain in their own services. Public HTTPS routing waits for a user-selected domain with valid DNS; private SSH-forwarded access can operate independently.

**Host evidence:** Saved SSH host key and named credential identify azure-prod-02, Ubuntu24.04, 4GB RAM, existing2GB swap, about19GB free disk, Nginx80/443, Watchtower3100, private databases. Docker is not installed. Node24 already exists under `/opt/node-v24.21.0-linux-x64`.
